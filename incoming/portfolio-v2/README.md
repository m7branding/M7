# Portfolio mockups v2: hand-over for the case pages

Delivered from the session "M7 Website project mockups" on 31 Oct 2026.
Branch: `claude/portfolio-mockups-v2`, based on `main`. Do not merge it. Copy what you need from it, as described below.

## What is on this branch

- `public/media/cases/<case>/v-NN-<kind>.webp`: new mockups, 2400 × 1500 WebP. They come in a clean, neutral style: white, grey and near-black backgrounds; devices that run off the frame; floating UI and brand pieces; paper, emboss, colour chips and brandbooks.
- `public/media/cases/<case>/v-motion-NN-<kind>.mp4` + `.webp` poster: motion clips, 1600 px wide, H.264, silent and loopable.
- `incoming/portfolio-v2/manifest.json`: every new file per case.
- `incoming/portfolio-v2/curation.json`: **the recommended final selection per case**.

  Each case page was compared on one sheet with three sources:
  1. what is on the case page now (`r-*`, `m-*` and the numbered brand and print photos);
  2. the other mockup import (gallery `https://claude.ai/artifact/2ScZAeHNZF5o3xbwgeSbjn`, overlapping on repairlab, jurgh-detailing, mindyourpass and kippenkar);
  3. the new v2 set.

  An art-director pass then picked the best per case. Per case, curation.json lists:
  - `cover`: the image for cards and overviews.
  - `gallery`: 12–20 items in page order. Items with `video` + `poster` are inline video blocks.
  - `heroVideo`: `"keep"` (keep the current r-hero), a new clip, or null.
  - `removeFromGallery`: current files that lost out to better or duplicate ones. Leave them out of the gallery, but keep the files; nothing needs deleting.
  - Each item carries `from`: `site`, `v2` or `other-import`. Other-import items reference the gallery item path; use the file you already imported for it.
- Case slugs follow the site. Five projects have no case page yet, marked `newCase: true`:
  - dng-shop (shop.digitalnewsgroup.com, separate from digital-newsgroup)
  - nova-special-cars (novaspecialcars.eu)
  - designers-house (designershouse.nl)
  - onderbouwd-investeren (onderbouwdinvesteren.nl)
  - battery-park-montessori (batteryparkmontessori.com)

  All five are live sites with an M7 credit. Create the case pages if they fit the site; otherwise skip them.

## How to apply

1. `git fetch origin claude/portfolio-mockups-v2` and `git checkout origin/claude/portfolio-mockups-v2 -- public/media/cases incoming/portfolio-v2`. Nothing existing is overwritten, because every new file starts with `v-`.
2. Apply `curation.json` per case: cover, gallery order and heroVideo, and leave `removeFromGallery` items out of the gallery. `src/content/generated/case-media.ts` is generated by `scripts/mockups`, so add the curation as a layer on top (or feed it into the generator) rather than hand-editing that file.
3. Delete the `v-*` files that end up unused, and remove the `incoming/` folder, so the deploy stays lean.
4. The owner's own instructions in your chat come first. Where they conflict with this selection, follow the owner.
